## Назва та опис проєкту

**HelloProject** — демонстраційний Java-проєкт, призначений для перевірки роботи
Build Engineer Agent. Агент автоматизує створення базової структури Maven-проєкту,
налаштування JUnit 5, підготовку GitHub Actions і перевірку коректності результату.

## Призначення Build Engineer Agent

Build Engineer Agent допомагає швидко й повторювано готувати Java-проєкти до
розробки та автоматичної перевірки. Він:

- ініціалізує Git-репозиторій;
- створює структуру Java-проєкту з Maven;
- налаштовує залежності та запуск тестів JUnit 5;
- додає workflow GitHub Actions для CI;
- перевіряє структуру, конфігурацію та результат складання.

Детальний опис компонентів і потоку виконання наведено в
[docs/architecture.md](docs/architecture.md).
Інструкція зі складання, запуску та використання міститься в
[docs/usage.md](docs/usage.md).

Java-проєктом є корінь цього Git-репозиторію. Він використовує стандартні
каталоги Maven `src/main/java` і `src/test/java`; окремої папки
`HelloProject/` або `tests/` немає.

## Запуск агента та основні команди

1. Відкрийте цей репозиторій у Visual Studio Code з підтримкою GitHub Copilot.
2. У панелі Chat виберіть агента **Build Engineer Agent** з файлу
   `.github/agents/build-engineer.agent.md`.
3. Надішліть агенту одну з команд нижче або команду `init` для повного
   початкового налаштування.

Доступні команди:

| Команда | Призначення |
|---|---|
| `git-init` | Ініціалізувати Git-репозиторій і перевірити його стан. |
| `create-project` | Створити базову структуру Java-проєкту HelloProject. |
| `create-build` | Створити або оновити Maven-конфігурацію та налаштувати JUnit 5. |
| `create-actions` | Створити workflow GitHub Actions для складання і тестування. |
| `check` | Перевірити структуру, конфігурацію, складання та тести. |
| `init` | Послідовно виконати повне налаштування проєкту. |

Команди слід виконувати з кореня репозиторію. Перед запуском переконайтеся, що
встановлені Java Development Kit, Maven і Git. У разі відсутності інструмента
агент повідомить про проблему та запропонує спосіб її усунення.
